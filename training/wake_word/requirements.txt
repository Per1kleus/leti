# The ISOLATED environment that trains the wake-word model. NOT Leti's.
#
# Nothing here is installed into the Leti runtime and nothing here is imported
# at runtime: Leti needs onnxruntime to RUN a wake-word model, and torch only to
# MAKE one. Keeping the two apart is why requirements.txt still has no torch in
# it - see the note there about a second torch installation.
#
# Reproduce with:
#   python3 -m venv trainenv
#   trainenv/bin/python -m pip install -r training/wake_word/requirements.txt
#
# Pinned, because the point of a training recipe is that it produces the same
# model twice. These are the versions the shipped hey_leti.onnx was built with,
# on Python 3.11.

# openWakeWord's own training code: the data augmentation, the feature
# computation, the model definition and the training loop all come from here.
# This recipe drives that code, it does not reimplement it.
openwakeword==0.6.0

# What openWakeWord's [full] extra asks for, pinned. torch is the CPU-capable
# PyPI wheel; download.pytorch.org's CPU-only index is not reachable from every
# network, and the PyPI wheel works either way.

# numpy 1.x on purpose: piper-sample-generator v2 and acoustics both want it.
